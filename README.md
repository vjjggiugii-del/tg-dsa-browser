# Tg DSA Browser

واجهة ويب سوداء لعرض جلسة متصفح بعيدة عبر Browserless وفتح صفحة Telegram DSA.

## تشغيل محلياً
1. ثبّت Node.js 20 أو أحدث.
2. فك ضغط المشروع وافتح مجلده في الطرفية.
3. نفّذ: `npm install`
4. انسخ `.env.example` إلى `.env` وضع قيمة `BROWSERLESS_WS_ENDPOINT` الصحيحة من لوحة Browserless.
5. شغّل: `npm start`
6. افتح `http://localhost:3000`.

## النشر
ارفع المجلد إلى خدمة استضافة تدعم تطبيق Node.js. اجعل أمر التشغيل `npm start`، وأضف `BROWSERLESS_WS_ENDPOINT` في إعدادات Secrets / Environment Variables لدى الاستضافة. لا ترفع ملف `.env` ولا تضع المفتاح في `public/`.

## إعداد Browserless
استخدم عنوان WebSocket المناسب لخطة/منطقة حسابك كما يظهر في لوحة Browserless أو وثائقه. المثال في `.env.example` قالب فقط وليس عنواناً صالحاً لحسابك. استخدم مفتاحاً جديداً بعد إلغاء المفتاح الذي سبق مشاركته.

## ملاحظات
- هذا المشروع لا يحل CAPTCHA ولا يتجاوزها؛ أكمل التحقق بنفسك.
- لا يرسل بلاغات تلقائياً؛ أنت تتحكم بالصفحة وتراجع أي بيانات قبل الإرسال.
- الجلسة مشتركة على مستوى نسخة الخادم الواحدة؛ لا تستخدمها لمستخدمين متعددين أو بيانات حساسة دون إضافة تسجيل دخول وعزل جلسات.
- أضف HTTPS وتسجيل دخول وحدود استخدام قبل نشره للعامة.
- إذا ظهرت مشكلة اتصال، راجع عنوان WebSocket والمنطقة وصلاحيات الخطة في لوحة Browserless.
